# Release-notes

> Hvad er ændret i hver version af GeoFA.

Hver gang GeoFA-specifikationen eller databasen ændres, udgives en release note. Den beskriver nye temaer, nye eller ændrede felter og ændrede værdiområder. Læs dem, hvis du har en løsning, der bygger på GeoFA-data, så du ved, hvad der påvirker dig.

## Indhold

| Version | Fil |
|---|---|
| 3.04 – asfalteret | [`Releasenote 3.04 (asfalteret).md`](Releasenote%203.04%20(asfalteret).md) |
| 3.03 – bevaringsværdige bygninger | [`Releasenote 3.03 (Bevaringsværdige bygninger).md`](Releasenote%203.03%20(Bevaringsværdige%20bygninger).md) |
| 3.02 – cykelkrydspunkter | [`Releasenote 3.02 (cykelkrydspunkter).md`](Releasenote%203.02%20(cykelkrydspunkter).md) |
| 1.0 – 3.01 | Ældre release notes som PDF |
| Skabelon | `GeoFA, releasenote X.XX.md` – bruges til nye release notes |

Release notes fra version 3.02 og frem er skrevet i markdown og kan læses direkte her på GitHub. Ældre versioner ligger som PDF.

## Sådan bruger du det

Vil du have besked, når der kommer en ny version, så følg med i [GeoFA's nyhedsmails](https://confluence.kds.dk/display/GS/Udsendte+nyhedsmails). Se også [GeoFA-specifikationen](https://confluence.kds.dk/display/GS/GeoFA-specifikation) for den samlede, aktuelle beskrivelse.

## Vedligeholdelse

Vedligeholdes af GeoFA-sekretariatet. Spørgsmål til en release: skriv til [geofa@geodanmark.dk](mailto:geofa@geodanmark.dk).
